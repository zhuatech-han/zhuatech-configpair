# ConfigPair 接口说明

## 认证与请求

路径前缀`/api`。先GET`/auth/csrf`取得header／token，写请求带此头；POST`/auth/login`提交username／password，使用HttpOnly／SameSite Strict会话。GET`/auth/me`读取当前岗位与导航；POST`/auth/logout`退出；POST`/auth/password`提交oldPassword／newPassword，成功后旧会话失效。错误返回HTTP状态及code，无口令、内部堆栈或数据库连接信息。

业务写入携带UUID格式requestKey及当前整个计划version。创建计划不需要version，所有子资源需jobId。状态、散列、创建人和系统时间不属于输入字段；未知字段、浮点整数ID及非法结果被拒绝。幂等键不能用于另一人、另一操作或不同内容。

| 方法及路径 | 行为／字段 |
|---|---|
| GET /options | 范围内部门、系统类型、安全账号候选、工作空间名称 |
| GET /jobs | search、status、page（0—1000）、size（1—50）、sort（newest／oldest／reference） |
| GET /jobs/{id} | 计划、参数、禁配、生成计划、实际覆盖、结果、历史及可用岗位标志 |
| POST /jobs、PUT /jobs/{id} | reference、name、departmentId、category、systemName、buildLabel、environment、instructions、reviewerId、operatorId |

| POST /factors/{id}/delete | jobId、note，删除未引用草稿参数 |
| POST /constraints、PUT /constraints/{id} | jobId、leftFactorId、leftValue、rightFactorId、rightValue、reason |

## 状态命令

| action | 岗位 | 允许状态与结果 |
|---|---|---|
| generate | 设计 | DRAFT／GENERATED → GENERATED，保存不可变快照 |
| submit | 设计 | GENERATED → SUBMITTED，检查当前生成与岗位 |
| return-plan | 指定独立复核 | SUBMITTED → DRAFT，活动生成失效 |
| approve | 指定独立复核 | SUBMITTED → APPROVED，冻结计划摘要 |
| start | 设计 | APPROVED → RUNNING，只开启软件登记 |
| acknowledge | 指定执行 | RUNNING且未收悉，记录收悉时间 |
| submit-report | 指定执行 | 已收悉且逐例明确 → REVIEW，申报须与阻塞事实一致 |
| return-result | 指定独立复核 | REVIEW → RUNNING，清除活动报告摘要供修订 |
| close | 指定独立复核 | REVIEW → CLOSED，派生PASSED／ISSUES／PARTIAL并封存 |
| cancel | 设计 | DRAFT／GENERATED／SUBMITTED／APPROVED → CANCELLED |

## 管理目录

GET`/admin/{type}`、POST`/admin/{type}`、PUT`/admin/{type}/{id}`、DELETE`/admin/{type}/{id}`；type为users、roles、departments、menus、permissions、dictionaries、settings。管理需要admin权限及ALL范围。

- users：username、displayName、password（修改留空保留）、roleId、departmentId、enabled；响应不含散列。
- roles：name、scope（ALL／DEPARTMENT／SELF）、permissions明确权限编码数组。
- departments：name。
- menus：name、nameEn、permissionCode、position、enabled；导航编码不可变。
- permissions：name；固定业务编码不能新增或删除。
- dictionaries：type、code、name、nameEn；被计划引用的类型编码不能改删。
- settings：value；固定companyName、timezone、maxRecords，名称不能增删。页面显示Asia/Shanghai。

不允许删除固定菜单、权限和系统参数。保留最后一个启用ALL管理员；外键保护业务引用。管理目录与业务DTO均拒绝额外内部字段。

## 主要错误

400：INVALID_INPUT、INVALID_VALUES、INVALID_FACTOR、INVALID_CONSTRAINT、INVALID_MODEL、SPACE_LIMIT、NO_VALID_CONFIGURATION、CASE_LIMIT、INVALID_RESULT、INVALID_OUTCOME。401：UNAUTHENTICATED。403：FORBIDDEN、OUT_OF_SCOPE、ASSIGNED_OPERATOR_ONLY、INDEPENDENT_REVIEW_REQUIRED（当前操作者不具备独立复核资格）。404：NOT_FOUND。409：STALE_VERSION、FROZEN、REQUEST_KEY_REUSED、VALUE_IN_USE、FACTOR_IN_USE、DUPLICATE_FACTOR、DUPLICATE_CONSTRAINT、GENERATION_REQUIRED、INCOMPLETE_RESULT、OUTCOME_MISMATCH、SNAPSHOT_CHANGED、LAST_ADMIN、CONFLICT、各类记录上限；指定复核人与历史设计者重合等计划冲突也可返回INDEPENDENT_REVIEW_REQUIRED。登录失败受限流保护。
